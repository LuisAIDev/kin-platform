# ADR-045: Glosas — Parser de Archivos Planos y Matching Engine

## Contexto
Las EPS devuelven glosas sobre las facturas RIPS (valor, código, cantidad,
autorización, vigencia, duplicado u otro). Cada EPS entrega archivos planos con
formatos propios (Colsanitas, Sura). KIN debe registrarlas, vincularlas a la
línea RIPS objetada y gestionar su apelación dentro de plazos.

## Decisión

### Componentes
- `Glosa` (entidad) + `GlosaType` (VALOR/CODIGO/CANTIDAD/AUTORIZACION/VIGENCIA/
  DUPLICADO/OTRO) + `GlosaStatus` (RECEIVED/ANALYZING/APPEALING/APPEALED/
  ACCEPTED/REJECTED/CONCILIATED/WRITTEN_OFF).
- `GlosaParser`: interpreta archivos planos con columnas
  `EPS_GLOSA_NUMBER | RIPS_BATCH_ID | RIPS_RECORD_ID | TYPE | CODE | DESCRIPTION | ORIGINAL_VALUE | GLOSA_VALUE`.
  - Colsanitas: delimitador `|`. Sura: delimitador `;`.
  - Ignora líneas vacías/`#` y malformadas.
- `MatchingEngine`: vincula glosa → `RipsRecord` por `ripsRecordId` directo o,
  en su defecto, por `ripsBatchId` + `glosaCode` contenido en `rips_line_data`.
- `AppealWorkflow`: máquina de estados; valida transiciones y expone
  `isAppealExpired`. Plazo de apelación por defecto: 15 días (`GlosaService`).
- `GlosaService`: importación multi-tenant (`TenantContext.get()`), CRUD,
  apelación, resolución y asignación.
- `GlosaController`: `/api/v1/billing/glosas/**`.

### Persistencia
Migración `V59__create_glosas.sql` con unique/indexes por organización, contrato,
estado y `appeal_deadline`.

## Consecuencias

### Positivas
- Importación uniforme de glosas de varias EPS sin acoplarse a un único formato.
- Trazabilidad glosa ↔ línea RIPS y estado auditable.
- Workflow explícito evita transiciones inválidas.

### Negativas
- El parser es heurístico (delimitador por contenido); formatos muy distintos
  requerirán un parser dedicado por EPS.
- El matching por código es textual (substring) y puede requerir refinar con
  reglas por tipo de glosa.

## Validación
- `GlosaParserTest` (pipe/Sura/malformadas), `MatchingEngineTest` (ID y batch+código),
  `GlosaServiceTest` (import tenant, transiciones). 13 tests PASS.
